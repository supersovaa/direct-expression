# avoid-redundant-negation

否定表現に関する二つの軽量スキルを公開します。

## Skills

### avoid-redundant-negation

肯定形の規則ですでに境界が定まっているとき、その補集合や同義の禁止事項を否定文で重ねて書く冗長さを整理します。

実際の規則は [`SKILL.md`](./SKILL.md) を参照してください。

### prefer-affirmative-expression

同じ意味と強さを保てる直接的な肯定表現がある場合に、その表現を選びます。
誤りや回避対象から出発した内容も、意図する行動・状態・条件・境界へ変換して表現します。

実際の規則は [`skills/prefer-affirmative-expression/SKILL.md`](./skills/prefer-affirmative-expression/SKILL.md) を参照してください。

## Responsibility boundary

`prefer-affirmative-expression` は一つの考えをどの形で表現するかを担当します。
`avoid-redundant-negation` は複数の文や規則の間で同じ境界を重ねる冗長さを整理します。
